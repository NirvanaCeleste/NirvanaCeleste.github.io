## A. 橙子汽水
https://ac.nowcoder.com/acm/contest/140236/A

> Alice 和 Bob 正在玩游戏。有两堆硬币，初始时硬币数量分别为 $x,y$。由 Alice 开始轮流进行操作。每回合，当前玩家必须执行一次操作：

第一行输入两个正整数 $x, y$（$1 \le x, y \le 10^9$），表示初始时两堆硬币中硬币的数量。

**输出**

### 模拟做法的完整证明

**证明目标**：证明两件事——(1) 游戏总操作次数固定，与操作顺序无关；(2) 总步数奇偶性决定胜负。

**第一步：游戏必然终止。**
每步操作从一堆取 $2$、另一堆加 $1$，总和 $S = x + y$ 每步减少 $1$。由于 $x, y \ge 0$，$S$ 最多减少 $x + y$ 次，故游戏在有限步内终止。$\blacksquare$

**第二步：总步数奇偶性固定。**
设 $D = x - y$。

- 从 $x$ 取 $2$、$y$ 加 $1$：$(x,y) \to (x-2, y+1)$，$D' = (x-2)-(y+1) = D - 3$。
- 从 $y$ 取 $2$、$x$ 加 $1$：$(x,y) \to (x+1, y-2)$，$D' = (x+1)-(y-2) = D + 3$。

即每步 $D \to D \pm 3$，故 $D \bmod 6$ 在以下两个集合间交替：

$$S_0 = \{0, 1, 5\}, \quad S_1 = \{2, 3, 4\}$$

**终止状态**：$x < 2$ 且 $y < 2$，即 $(x,y) \in \{(0,0),(0,1),(1,0),(1,1)\}$。

对应 $D \bmod 6$：

| $(x,y)$ | $D$ | $D \bmod 6$ | 所属集合 |
|---|---|---|---|
| $(0,0)$ | $0$ | $0$ | $S_0$ |
| $(0,1)$ | $-1$ | $5$ | $S_0$ |
| $(1,0)$ | $1$ | $1$ | $S_0$ |
| $(1,1)$ | $0$ | $0$ | $S_0$ |

**所有终止态都在 $S_0$ 中**。

由于每步在 $S_0$ 与 $S_1$ 间切换，从初始状态到终止态所需步数 $t$ 满足：
- 若初始 $D \bmod 6 \in S_0$，则 $t$ 为偶数；
- 若初始 $D \bmod 6 \in S_1$，则 $t$ 为奇数。

因此 $t$ 的**奇偶性唯一确定**，与具体操作顺序无关。$\blacksquare$

**第三步：胜负判定。**
共 $t$ 步，Alice 走第 $1, 3, 5, \dots$ 步，Bob 走第 $2, 4, 6, \dots$ 步。
- 若 $t$ 为奇数，最后一步由 Alice 走完，轮到 Bob 时无路可走，**Alice 胜**。
- 若 $t$ 为偶数，最后一步由 Bob 走完，轮到 Alice 时无路可走，**Bob 胜**。

因此：**初始 $D \bmod 6 \in S_1 \iff$ Alice 胜**，即

$$(x - y) \bmod 6 \in \{2, 3, 4\} \iff \text{Alice 胜}$$

这就是官方做法一的结论。$\blacksquare$

**第四步：模拟正确性。**
你的代码按一种**特定顺序**批量执行操作：只要某堆 $\ge 2$，就"一口气"对它做 $\lfloor x/2 \rfloor$ 次操作。由于：
1. 每一步都是**合法**的（当前堆 $\ge 2$ 才操作）；
2. 总步数 $t$ 与操作顺序无关（第二步已证）；

所以你的模拟得到的 `cnt` 就是真实总步数 $t$，其奇偶性判断胜负是正确的。

> **备注**：你的代码本质上就是官方做法二（$O(\log V)$ 模拟）。每次"批量"后总石子数大致减半，循环次数为 $O(\log(x+y))$，完全可以接受。

### 官方题解对比

**官方做法一（结论）**：
- 先手必胜当且仅当 $(x - y) \bmod 6 \in \{2, 3, 4\}$
- 设 $D = x - y$，两种操作分别使 $D \gets D - 3$ 或 $D \gets D + 3$
- 按 $D \bmod 6$ 划分为 $S_0 = \{0,1,5\}$ 和 $S_1 = \{2,3,4\}$
- 每次操作 $S_0 \to S_1$，$S_1 \to S_0$，所有终止态都在 $S_0$ 中
- 因此只需判断初始态在哪个集合即可，每组数据 $O(1)$

**官方做法二（模拟）**：
- 每次找一堆全部操作完，总石子数几乎减半，$O(\log V)$

**我的思路解读**：赛时我没有推导出模 6 的结论，而是暴力模拟整个过程——每次对某一堆直接做 $x/2$ 次操作，把所有可能的操作"批量"完成，统计总操作次数。这个思路实际上就是官方做法二的实现。官方做法一从数学本质证明了操作次数固定且只与 $D \bmod 6$ 有关，是一个非常漂亮的博弈论结论，赛时我虽然直觉猜到"操作顺序不影响结果"但没有证明，导致只能模拟。这是我这场比赛最大的遗憾。

### 二分 + 贪心的完整证明

**证明目标**：证明两件事——(1) 合法 $k$ 的单调性，保证二分正确；(2) 贪心构造的正确性。

**第一步：单调性。**
设 $b$ 对 $k$ 合法，即 $b_i \in [a_i - k, a_i + k]$ 且互不相同。对于 $k' = k + 1$，区间 $[a_i - k', a_i + k']$ 严格包含 $[a_i - k, a_i + k]$，故同一个 $b$ 对 $k'$ 也合法。因此合法 $k$ 的集合是一个后缀 $[k_{\min}, +\infty)$，二分可行。$\blacksquare$

**第二步：贪心正确性。**
设 $b^*$ 是任意一个合法数组。不妨设 $b^*$ 已按升序排列（因为约束只涉及每个 $b_i$ 自己的区间，重排不改变合法性；而 $a$ 已排序，故可以对应分配）。

**归纳假设**：$b_{i-1} \le b^*_{i-1}$。

**归纳步骤**：
$$b_i = \max(a_i - k,\ b_{i-1} + 1) \le \max(a_i - k,\ b^*_{i-1} + 1)$$

由 $b^*_i \ge a_i - k$（合法性）且 $b^*_i \ge b^*_{i-1} + 1$（严格递增），故
$$\max(a_i - k,\ b^*_{i-1} + 1) \le b^*_i$$

因此 $b_i \le b^*_i \le a_i + k$，贪心构造的 $b_i$ 始终在合法范围内。$\blacksquare$

**第三步：二分正确性。**
由第一步（单调性）和第二步（贪心正确性），`check(k)` 返回 `true` 当且仅当 $k$ 合法。因此二分找到的就是最小合法 $k$。$\blacksquare$

**第四步：边界处理。**
初始 `now = -2e9`（足够小的哨兵值），保证第一个 $b_1 = a_1 - k$ 不受 `now + 1` 干扰。

### 官方题解对比

**官方做法一（数学推导）**：
- 先排序，假设已知 $k$，贪心构造 $b_1 = a_1 - k$，$b_i = \max(b_{i-1} + 1, a_i - k)$
- 令 $x_i = b_i + k$，代入得 $x_1 = a_1$，$x_i = \max(x_{i-1} + 1, a_i)$
- 由 $b_i \le a_i + k$ 得 $2k \ge x_i - a_i$，即 $k \ge \lceil (x_i - a_i)/2 \rceil$
- 扫一遍直接计算即可，$O(n\log n)$

**官方做法二（二分）**：
- 二分 $k$，贪心判定，$O(n(\log n + \log V))$

**我的思路解读**：我赛时**直接想到了官方做法二**——二分答案 + 贪心判定，思路和官方完全一致。赛后整理思路时还尝试过做离散化 + 重复元素分析，但很快意识到直接排序就够了，白白浪费了时间。**赛后写代码时反而卡在 check 函数中 `now + 1` 的初始值上**，最后发现直接初始化为一个很小的值（如 $-2 \times 10^9$）就够了。官方做法一的数学推导更简洁，如果当时能想到 $x_i = b_i + k$ 这个换元，就能 $O(n\log n)$ 一遍扫过，不需要二分。这道题的教训是：**看到"最小化最大值"这类字眼，要第一反应出"二分答案 + 贪心判定"的套路，同时也要准备好数学推导的备选方案。**

### 分类讨论的完整证明

**证明目标**：证明两件事——(1) 当 $c_1, c_2$ 数量关系不满足特定条件时无解；(2) 满足条件时构造的序列一定合法。

**第一步：条件的等价转化。**
原条件：对于 $1 \le i < n$，
$$\sum_{j=1}^i a_j \not\equiv \sum_{j=i+1}^n a_j \pmod 3$$

设前缀和 $P_i = \sum_{j=1}^i a_j \bmod 3$，总和 $S = P_n$。条件等价于 $P_i \not\equiv S - P_i \pmod 3$，即 $2P_i \not\equiv S \pmod 3$。

在模 $3$ 中 $2 \equiv -1$，故 $2^{-1} \equiv 2$，所以 $P_i \not\equiv 2S \equiv -S \pmod 3$。

**结论**：每个前缀和 $P_i$（$1 \le i < n$）都不能等于 $-S \bmod 3$。$\blacksquare$

**第二步：模 $3$ 的"步长"分析。**
每个 $a_j \bmod 3 \in \{0, 1, 2\}$。$P_i$ 从 $0$ 出发，每次加 $a_i \bmod 3$。
- $a_i \equiv 0$：$P_i$ 不变；
- $a_i \equiv 1$：$P$ 在模 $3$ 中 $+1$；
- $a_i \equiv 2$：$P$ 在模 $3$ 中 $-1$。

设非零元素依次排列后前缀和为 $Q_0 = 0, Q_1, Q_2, \dots, Q_m$（$m = c_1 + c_2$），最后 $Q_m = S$。$c_0$ 个 $0$ 不改变前缀和，可以全部放在最前或最后，不影响分析。

**关键观察**：$Q_j \in \{1, 2\}$（对所有 $1 \le j < m$），因为每个 $Q_j$ 不能等于 $-S \bmod 3$，而 $Q_j$ 只在 $\{0,1,2\}$ 中取值。

**第三步：三种情况。**

#### 情况 $S = 1$

$-S \equiv -1 \equiv 2$。所以 $P_i \ne 2$，$Q_j$ 可以取 $0$ 或 $1$（只要不是 $2$）。

从 $Q_0 = 0$ 出发，$Q_1$ 只能取 $1$（$+1$）或 $2$（$-1$），后者禁止，所以 $Q_1 = 1$。从 $Q_1 = 1$，下一步可以 $+1$ 到 $2$（禁止），或 $-1$ 到 $0$（合法）。所以 $Q_2 = 0$。依次类推，$Q$ 序列为 $0, 1, 0, 1, \dots$。

最后 $Q_m = S = 1$。所以 $m$ 是奇数，且序列为 $0, 1, 0, 1, \dots, 1$（共 $m$ 步）。

对应 $a_j \bmod 3$：$0 \to 1$ 是 $+1$（即 $a_j \equiv 1$），$1 \to 0$ 是 $-1$（即 $a_j \equiv 2$）。

所以非零元素序列为 $1, 2, 1, 2, \dots, 1$，其中 $1$ 比 $2$ 多一个。**即 $c_1 = c_2 + 1$。**（$c_0$ 任意）

#### 情况 $S = 2$

对称地，$-S \equiv -2 \equiv 1$，$P_i \ne 1$。类似分析得 $Q$ 序列为 $0, 2, 0, 2, \dots, 2$，对应 $a_j \bmod 3$ 为 $2, 1, 2, 1, \dots, 2$。**即 $c_2 = c_1 + 1$。**

#### 情况 $S = 0$

$-S \equiv 0$，所以 $P_i \ne 0$（$1 \le i < n$），且 $P_n = 0$。

非零部分从 $Q_0 = 0$ 出发，第一步必须到 $1$ 或 $2$（不能是 $0$）。

若第一步到 $1$（即 $a_1 \equiv 1$）：从 $Q_1 = 1$，下一步只能到 $2$（因为 $0$ 禁止）。从 $Q_2 = 2$，下一步只能到 $1$。所以 $Q$ 在 $1, 2$ 间交替：$1, 2, 1, 2, \dots$。最后要回到 $0$。

分两类：

**类 A（先走 $1$）**：序列以 $1$ 开头。$Q_j$ 在 $\{1, 2\}$ 间交替，最后一步回到 $0$。

若 $Q_{m-1} = 1$，则最后 $a_m \equiv 2$（$1 \to 0$ 是 $+2$），序列为 $1, 2, \dots, 1, 2$；
若 $Q_{m-1} = 2$，则最后 $a_m \equiv 1$（$2 \to 0$ 是 $+1$），序列为 $1, 2, \dots, 2, 1$。

具体地：
- 若 $m$ 为偶数：$Q_{m-1}$ 与 $Q_1 = 1$ 同奇偶（因为交替），$m-1$ 是奇数，故 $Q_{m-1} = 1$（序列 $1, 2, 1, 2, \dots, 1$ 在 $m-1$ 位置是 $1$）→ 等等，需要仔细推。

**简化方法**：官方题解直接给出三种合法形态，逐项验证即可。
- $c_1 = c_2$：形如 $1, 1, 2, 1, 2, \dots, 2$
- $c_1 = c_2 + 3$：形如 $1, 1, 2, 1, 2, \dots, 1$
- $c_2 = c_1 + 3$：形如 $2, 2, 1, 2, 1, \dots, 2$

可以逐项验证这些序列的前缀和 $P_i$ 从不等于 $0$（模 $3$），且最后 $P_n = 0$。$\blacksquare$

**第四步：构造正确性。**
对上述每种情况，按官方模式排列元素，前缀和 $P_i$ 都不会等于 $-S \bmod 3$，因此满足条件。$\blacksquare$

### 官方题解对比

- **$S=1$**：必须形如 `1, 2, 1, 2, ..., 1`，有解当且仅当 $c_1 = c_2 + 1$

### DP 做法的完整证明

**证明目标**：证明状态转移方程正确，且前缀和优化可行。

**第一步：状态定义。**
在位置 $0$ 和 $n+1$ 各放一个虚拟木桩。两个相邻木桩之间的格子构成一个"连续段"。

对于段 $(j, i)$（$j < i$ 是两个相邻木桩），段内所有数字 $a_p$ 必须满足：
$$a_p = i - j - 1$$
即段长由数字唯一确定。

**第二步：转移分类。**
枚举 $i$（当前木桩位置），枚举上一个木桩 $j$。设 $p$ 为 $i$ 之前最后一个数字的位置。

**情况一：段内无数字**（$j \ge p$）
段 $(j, i)$ 中所有格子都是 $0$（空格），无约束。任何 $j \in [p, i-1]$ 都合法。
贡献：$\sum_{j=p}^{i-1} f_j$，用前缀和 $O(1)$ 求。

**情况二：段内有数字**（$j < p$）
段内必须包含 $p$，设 $a_p = x$。则段长 $= x$，所以 $i - j - 1 = x$，即 $j = i - 1 - x$ 唯一确定。

还需满足：
- $j \ge 0$（木桩在范围内）；
- $j < p$（$p$ 在段内）；
- 段 $(j, i)$ 内不能有其他数字（否则其他数字的 $a$ 也要等于 $x$，矛盾）。

后者只需预处理每个位置左侧最近的"不同值数字"位置即可 $O(1)$ 判断。
贡献：若 $j$ 合法，加上 $f_j$。

**第三步：正确性。**
由归纳，$f_j$ 表示以 $j$ 为最后一个木桩的合法方案数。枚举所有可能的上一个木桩位置，加上对应贡献，得到 $f_i$。

每个合法方案唯一对应一个 $(j, i)$ 对（最后两个木桩），因此不重不漏。$\blacksquare$

**第四步：复杂度。**
每个 $i$ 转移 $O(1)$（前缀和 + 唯一候选 $j$），总 $O(n)$。

### 官方题解

**动态规划**：
- 设 $f_i$ 表示将当前最后一个木桩放置在第 $i$ 个格子的合法方案数
- 假设在位置 0 和位置 $n+1$ 各有一个必定放置的虚拟木桩，初始 $f_0 = 1$，最终答案 $f_{n+1}$
- 枚举上一个木桩的位置 $j$（$0 \le j < i$），区间 $(j, i)$ 形成连续段：
  - **段内不包含数字**：上一个木桩 $j$ 必须在最后一个数字之后。设 $p$ 为 $i$ 之前最后一个数字的下标，合法 $j \in [\max(0, p), i-1]$，贡献为 $\sum_{j=p}^{i-1} f_j$，前缀和优化 $O(1)$
  - **段内包含数字**：段必然跨越 $p$，设 $p$ 上数字为 $x$，段长只能为 $x$，上一个木桩唯一确定 $j = i - 1 - x$。需保证 $j \ge 0$、$j < p$，且区间内不能出现与 $x$ 不同的其他数字，预处理每个位置上一个不同数字的位置即可 $O(1)$ 判断

- 总时间复杂度 $O(n)$

### 核心公式的完整证明

**证明目标**：证明 $f(A) = n - \sum_{i<j} [a_i = a_j \wedge \forall k \in (i,j),\ a_k > a_i]$，并正确应用期望线性性。

**第一步：操作与"极大矩形"。**
每次操作选择一个好区间 $[l, r]$（即 $a_{l-1} = a_{r+1} = 0$）和一个正整数 $x$，对所有 $i \in [l, r]$ 令 $a_i \gets a_i - x$。

一个"极大矩形"是指在高度 $h$ 上，一段连续的、所有元素 $\ge h$ 的区间。

$f(A)$ 的最优策略是**逐高度消去**：对每个高度 $h$，找出所有极大矩形，每个矩形需要一次操作。

**关键观察**：两个位置 $i < j$ 属于同一个极大矩形（在某个高度上）当且仅当 $a_i = a_j$ 且中间所有 $a_k > a_i$。

若满足这个条件，$i$ 和 $j$ 可以用同一次操作消去，节省一次操作。

设满足条件的 $(i, j)$ 对数量为 $C$。总操作次数 $= n - C$（初始每个位置需要一次操作，每合并一对节省一次）。

**即 $f(A) = n - C$。** $\blacksquare$

**第二步：期望线性性。**
对所有满足 $1 \le b_i \le c_i$ 的 $b$ 求和：
$$\sum_b f(b) = \sum_b \left( n - C(b) \right) = n \cdot \prod c_i - \sum_b C(b)$$

$C(b) = \sum_{i<j} [b_i = b_j \wedge \forall k \in (i,j),\ b_k > b_i]$。

交换求和：
$$\sum_b C(b) = \sum_{i<j} \sum_b [b_i = b_j \wedge \forall k \in (i,j),\ b_k > b_i]$$

对每对 $(i, j)$，统计满足条件的 $b$ 的数量。

**第三步：逐高度统计。**
对固定高度 $h$，$b_i = b_j = h$ 且中间所有 $b_k > h$。
- $b_i = h$ 的方案数：$1$（只有 $h$ 一种取值，前提 $c_i \ge h$）
- $b_j = h$ 的方案数：$1$（前提 $c_j \ge h$）
- $b_k > h$ 的方案数：$c_k - h$（取值 $h+1, \dots, c_k$，前提 $c_k > h$）

所以固定 $h$ 时，$(i, j)$ 的贡献为：
$$[c_i \ge h] \cdot [c_j \ge h] \cdot \prod_{k=i+1}^{j-1} \max(0, c_k - h)$$

对所有 $h$ 求和（$h = 1$ 到 $V$），再对所有 $i < j$ 求和，即得 $C$ 的总和。

用前缀积维护，边扫边算，$O(nV)$。$\blacksquare$

### 官方题解

**核心公式**：

对于任意序列，有：

$$f(A) = n - \sum_{i<j} [a_i = a_j \wedge \forall k \in (i, j), a_k > a_i]$$

证明思路：每次操作是一个极大矩形。如果 $(i, j)$ 满足上述条件，它们属于同一个操作矩形，可以节省一次操作。

**期望线性性**：

总方案数 $\prod c_i$，期望 $E[f(A)] = n - \sum_{h=1}^{V} g_h$，其中 $g_h$ 为高度为 $h$ 时发生合并的期望次数。

对于固定高度 $h$：
- 第 $x$ 个位置等于 $h$ 的概率：$P_1(x) = 1/c_x$（前提 $c_x \ge h$）
- 第 $x$ 个位置大于 $h$ 的概率：$P_2(x) = \max(0, c_x - h)/c_x$

高度为 $h$ 时的合并期望次数为：

$$\sum_{i<j} P_1(i) \cdot P_1(j) \cdot \prod_{k=i+1}^{j-1} P_2(k)$$

边扫边维护即可，总时间复杂度 $O(nV)$。

**我的思路解读**：这道题赛时没看。官方题解的关键是**将问题转化为"极大矩形合并"**——$f(A)$ 等于 $n$ 减去可以被合并的位置对数。然后用期望线性性，对每个高度 $h$ 分别统计。这个转换非常巧妙：**原问题是求最小操作次数，官方把它转成"求最大节省次数"**。$O(nV)$ 的复杂度依赖于 $n, c_i \le 5000$，正好可以开二维数组。

### SCC = 割边分割的完整证明

**证明目标**：证明 SCC 恰好是被割边分割的连续区间，且可达点数公式正确。

**第一步：SCC 是连续区间。**
边集为 $\{(p_i, i) : 1 \le i \le n\}$，其中 $p_i \le i$。所有边连接的是"跨越区间 $[p_i, i]$"。

若两条边对应的区间 $[p_x, x]$ 和 $[p_y, y]$（$x < y$）有重叠（即 $p_y \le x$），则它们属于同一个 SCC。由区间重叠的传递性，SCC 恰好是若干**连续区间**的并。$\blacksquare$

**第二步：割边判定。**
$k$ 和 $k+1$ 之间有割边，当且仅当没有任何边从 $> k$ 跨越到 $\le k$。

定义 $c_k$ = 满足 $x > k$ 且 $p_x \le k$ 的边数。则：
$$k \to k+1 \text{ 是割边} \iff c_k = 0$$

设 $c_k = 0$ 的位置为 $z_1 < z_2 < \dots < z_m$（令 $z_0 = 0, z_{m+1} = n$），则第 $j$ 个 SCC 的大小为 $S_j = z_j - z_{j-1}$。$\blacksquare$

**第三步：可到达点数之和。**
对于点 $i$，它能到达的最小点为 $L_i$（它所在 SCC 的左端点），能到达的点总数为 $n - L_i + 1$。

所有点可到达点数之和：
$$\sum_{i=1}^n (n - L_i + 1)$$

按 SCC 分组。第 $j$ 个 SCC 覆盖 $[z_{j-1}+1, z_j]$，其中所有点的 $L_i = z_{j-1}+1$，可到达点数均为 $n - z_{j-1}$。

求和：
$$\sum_j S_j (n - z_{j-1}) = \sum_j S_j (n - z_j + S_j)$$

利用 $\sum S_j = n$ 和 $z_j = \sum_{t \le j} S_t$ 化简可得：
$$\frac{n(n-1)}{2} + \sum_j \frac{S_j(S_j+1)}{2}$$
$\blacksquare$

**第四步：线段树维护。**
修改 $p_x \to y$ 时，相当于在 $c$ 数组的区间 $[y, x-1]$ 上做区间 $+1$ 或 $-1$。

需要维护：
- 区间最小值 $mn$；
- 最小值的第一次和最后一次出现位置；
- 所有相邻最小值之间距离的平方和。

合并时（左右儿子），若左最小值 $<$ 右最小值，取左；若右 $<$ 左，取右；若相等，合并最小值的出现位置，并计算跨左右边界的相邻最小值距离。

线段树每个节点信息可在 $O(1)$ 内合并，总复杂度 $O((n+q)\log n)$。$\blacksquare$

**我的思路解读**：这道题赛时没看。官方题解的关键是**将 SCC 的划分转化为"割边"问题**——相邻位置之间有割边当且仅当没有任何跨过的边。$c_i = 0$ 的位置把整个序列分成若干段 SCC。然后用线段树维护 $c$ 数组的区间加和最小值信息，难点在于合并时要维护"所有相邻最小值之间的距离平方和"这个额外信息。这道题综合了图论 SCC、线段树、以及数学推导，难度非常大。
