## A
https://codeforces.com/contest/2244/problem/A

在一节几何课上，伊斯坎德尔觉得非常无聊，于是决定在尤拉的笔记本上画画。为此，他在上面画了一排横线。有的线长，有的线短，有的地方还是空的。

页面由一个字符串 $s$ 表示，其中字符 "*" 表示纸张的空白部分，字符 "#" 表示已画线的一厘米。连续的 "#" 字符序列构成一行。

尤拉决定擦掉所有的线，并让伊斯坎德尔帮助他：他们将同时从两端擦掉其中一条线。

- 每秒钟，伊斯坎德尔从右端擦除 $1$ 厘米，尤拉从左端擦除 $1$ 厘米。
- 如果当前线条的长度是 $1$ 或 $2$ 厘米，那么下一秒它就会被完全擦除，过程结束。

尤拉想选择一条线，以便和伊斯坎德尔一起尽可能长时间地擦除它。帮他确定这个最长时间。如果页面上没有线条，答案是 $0$ 秒。

**输入**

第一行包含一个整数 $t$（$1 \le t \le 2500$）— 测试用例数。

每个测试用例的第一行包含一个整数 $n$（$1 \le n \le 10$）— 字符串 $s$ 的长度。

每个测试用例的第二行包含一个长度为 $n$ 的字符串 $s$，由字符 '#' 和 '*' 组成。

**输出**

对于每个测试用例，输出一个整数 — 擦除一行所需的最长时间。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int maxx = 100010;
int t;
string s;
long long n;
long long solve(){
	long long len = n,ans = 0,tmp = 0;
	if(len == 0) return 0;
	if((len == 1 && s == "#") || (len == 2 && s != "**")) return 1;
	else if(len == 1 && s == "*") return 0;
	if(s[0] == '#') tmp = 1,ans = 1; 
	for(int i=1;i<len;i++){
		if(tmp == 0 && s[i] == '#') tmp++;
		else if(s[i] == s[i-1] && s[i] == '#') tmp++;
		else tmp = 0;
		ans = max(tmp,ans);
	}
	if(ans > 2) return ans%2==1?(ans/2)+1:ans/2;
	else if(ans == 0) return 0;
	else return 1;
}
int main(){
	cin>>t;
	while(t){
		t--;
		cin>>n>>s;
		cout<<solve()<<endl;
	}
	return 0;	
}
```

遍历字符串统计每段连续 `#` 长度；长度 1/2 耗时 1，长度 $L > 2$ 时耗时 $\lceil L/2 \rceil$，取全局最大值。

## B
https://codeforces.com/contest/2244/problem/B

前缀和贪心，判断能否构造严格递增序列。

#### 问题陈述
众所周知，尼基塔热爱阅读。今天，他把自己的房间弄得乱七八糟，把书摆成了 $n$ 堆，从左到右依次编号为 $1$ 到 $n$。第 $i$ 堆里有 $a_i$ 本书。如果除了最右边的一叠之外，其他每叠的书籍数量都严格少于其右边的一叠，即数组 $a$ 是严格递增的，那么这种排列就叫做整齐。

尤拉想通过执行以下任意次数的操作使排列整齐：

1. 选择一个书堆 $i$，使得 $1 \le i < n$ 且 $a_i > 1$。
2. 从书堆 $i$ 顶端取出 $1$ 本书，这样 $a_i$ 就减少了 $1$。
3. 把这本书放到书堆 $i+1$ 的顶端，因此 $a_{i+1}$ 增加 $1$。

判断尤拉能否使排列整齐。

**输入**

第一行包含一个整数 $t$（$1 \le t \le 10^4$）— 测试用例数。

每个测试用例的第一行包含一个整数 $n$（$1 \le n \le 2 \cdot 10^5$）— 堆栈数量。

每个测试用例的第二行包含 $n$ 个整数 $a_i$（$1 \le a_i \le 10^9$）— 每个堆栈的初始书籍数量。

保证所有测试用例中 $n$ 的总和不超过 $2 \cdot 10^5$。

**输出**

对于每个测试用例，如果 Yura 可以使排列整齐，则输出 "Yes"，否则输出 "No"。

```cpp
#include <bits/stdc++.h>
const int maxx = 200010;
int n,t;
long long a[maxx];
long long sum[maxx];
bool check(){
	for(int i=2;i<=n;i++) if(sum[i] < 1LL*i*(i+1)/2) return 0; 
	return 1;
}
int main(){
	cin>>t;
	while(t){
		t--;
		cin>>n;
		memset(sum,0,sizeof(sum));
		cin>>a[1];
		sum[1] = a[1];
		for(int i=2;i<=n;i++) cin>>a[i],sum[i] = sum[i-1] + a[i];
		if(check()) cout<<"Yes"<<endl;
		else cout<<"No"<<endl;	
	}
	return 0;	
}
```

$1,2,\dots,i$ 是最小严格递增序列，若原数组前 $i$ 项总和达不到该值，无论怎么排都无法严格递增。

## C
https://codeforces.com/contest/2244/problem/C

GCD分块+排序，排列可升序判定。

#### 问题陈述
斯捷潘发现了长度为 $n$ 的排列 $p$。当然，他决定对其进行排序。为了让排序过程更有趣，他选择了两个正整数 $x$ 和 $y$（$x + y \le n$）并定义了一个交换元素的规则。

在一步棋中，斯捷潘可以选择 $i$ 和 $j$ 这两个索引（$1 \le i, j \le n$）并交换 $p_i$ 和 $p_j$ 中的元素，条件是以下条件中至少有一个成立：

- $|i - j| = x$
- $|i - j| = y$

斯捷潘想知道是否有可能使用任意数量的此类操作将排列按升序排序。请帮助他回答这个问题。

**输入**

第一行包含一个整数 $t$（$1 \le t \le 10^4$）— 测试用例的数量。

每个测试用例的第一行包含三个整数 $n, x, y$（$1 \le x, y \le n \le 2 \cdot 10^5$，$x + y \le n$）— 数组的长度和斯捷潘选择的数字。

每个测试用例的第二行包含 $n$ 个整数 $p_i$（$1 \le p_i \le n$）— 数组 $p$；保证 $p$ 是一个排列。

保证所有测试用例中 $n$ 的总和不超过 $2 \cdot 10^5$。

**输出**

对于每个测试用例，如果可以用给定的 $x$ 和 $y$ 对排列进行排序，则输出 "Yes"，否则输出 "No"。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int maxx = 200020;
int t,n,x,y,tot;          // 修正：原先写成 \(n,x,y\) 导致语法错误
int p[maxx],tmp[maxx],head[maxx],last[maxx];
int gcd(int a,int b){return b > 0 ? gcd(b,a%b) : a;} 
bool check(){
	if(gcd(x,y) == 1) return 1;
	int len = gcd(x,y);
	tot = 0;
	for(int i=1;i<=len;i++){
		for(int j=i;j<=n;j+=len){
			tot++; 
			tmp[tot] = p[j];
			if(j == i) head[i] = tot;
		}
		last[i] = tot;
	} 
	for(int i=1;i<=len;i++) sort(tmp+head[i],tmp+last[i]+1);
	tot = 0;
	for(int i=1;i<=len;i++){
		for(int j=i;j<=n;j+=len){
			tot++;
			p[j] = tmp[tot];
		}
	} 
	for(int i=2;i<=n;i++) if(p[i] <= p[i-1]) return 0;
	return 1;
}
int main(){
	cin>>t;
	while(t){
		t--;
		cin>>n>>x>>y;
		for(int i=1;i<=n;i++) cin>>p[i];
		tot = 0;
		if(check()) cout<<"Yes"<<endl; 
		else cout<<"No"<<endl; 
	}
	return 0;	
}
```

$\gcd(x,y)$ 为分组步长，每组单独排序后全局校验严格递增；$g=1$ 时所有下标可任意交换，必然能排升序。
